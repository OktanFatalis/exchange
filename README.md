# Конвертер валют (FastCurrency) 2.0

Офлайн-конвертер для Android: 4 ячейки, мгновенный пересчёт, ~166 валют и 30 криптовалют,
графики курса любой пары от 2 часов до 30 лет. APK ≈ 60 КБ, без сторонних библиотек.

## Возможности

- **Ввод с разрядами**: 10 000 и 100 000 видны сразу, пробелы ставятся по мере набора,
  курсор не прыгает. Разделитель дроби — запятая (точка тоже понимается).
- **Криптовалюты**: BTC, ETH, USDT, SOL, TON и ещё 25. Курсы — Binance, запасной
  источник — Coinbase. Обновляются при запуске, если старше 5 минут.
- **Ячейки по центру экрана** — до всего достаёт большой палец одной руки.
- **График пары**: удерживайте одну валюту (она подсветится), затем вторую.
  Периоды 2Ч · 1Д · 1Н · 1М · 6М · 1Г · 5Л · 10Л · 15Л · 30Л. Палец по графику показывает
  курс и дату в любой точке, ⇄ меняет пару местами, свайп вниз закрывает.
  На графике: минимум, максимум, уровень начала периода, изменение в % и среднее.
- **Источники истории**: Binance (крипто), Yahoo Finance (внутридневные данные),
  ЕЦБ (с 1999 г.), ЦБ РФ (рубль с 1992 г.). Если история короче периода, это написано
  под графиком («данные с …»).
- **Офлайн**: курсы, выбранные валюты и сумма хранятся локально, первый запуск без сети
  работает по встроенному снимку курсов.

## Сборка

Android Studio → Open → папка `FastCurrency` → Run. Release: `./gradlew assembleRelease`.
Минимальная версия Android — 7.0 (API 24), target — API 35.

Готовый `FastCurrency.apk` в корне подписан другим ключом, чем ваши отладочные сборки:
если на телефоне стоит прежняя версия, удалите её перед установкой.

## Структура

```
MainActivity.kt  экран, ячейки, ввод, выбор валюты и пары
ChartSheet.kt    панель графика, переключатель периода
ChartView.kt     отрисовка графика (Canvas), анимации, касания
History.kt       загрузка истории, сведение пары, прореживание
Rates.kt         текущие курсы: ER-API, ЦБ РФ, Binance, Coinbase
Store.kt         состояние и кеш в одном файле
Money.kt         разбор и форматирование чисел
Currencies.kt    справочник валют
Dates.kt         даты без SimpleDateFormat
Ui.kt            палитра, панели, общие элементы
Seed.kt          встроенный снимок курсов
```
